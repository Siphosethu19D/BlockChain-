## What the Code Does

The program demonstrates how a simple blockchain transaction system works:

- Question 1: Defines a transaction with a sender, recipient, amount, timestamp, and signature field.
- Question 2: Creates transactions and converts them to and from JSON.
- Question 3: Validates transactions and creates a simple mempool that stores valid transactions.
- Question 4: Demonstrates a valid transaction from Alice to Bob and an invalid transaction from Carol.
- Question 5: Explains how the simplified account-style model relates to Bitcoin's UTXO model.
