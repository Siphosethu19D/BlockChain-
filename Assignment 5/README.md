# Assignment 5

## Requirements

* Python 3.10 or later
* Python standard library only



## What the Code Does

The program implements a simplified blockchain.

* **(a)** Implements `append_block()`, `verify_chain()`, and per-block hash checks.
* **(b)** Integrates the previous Block and transaction modules.
* **(c)** Demonstrates valid chain verification, detection of a tampered block, and why repairing hashes alone is not sufficient when a Proof-of-Work difficulty rule is applied.
* **(d)** Explains why blockchain immutability is based on economic and computational costs rather than being absolute.
* **Part B:** Calculates a Merkle root from four transactions and demonstrates Simplified Payment Verification (SPV).
